# 🏡 Dự án Dự báo Giá nhà (House Price Prediction)

Dự án này sử dụng thuật toán **Hồi quy tuyến tính (Linear Regression)** trong Học máy để dự báo giá nhà dựa trên các đặc trưng của ngôi nhà.

## 🛠️ Công nghệ sử dụng
- **Ngôn ngữ:** Python 3.x
- **Thư viện:** Pandas, Numpy, Scikit-learn

## 📁 Cấu trúc dự án
- `data/`: Chứa dữ liệu đầu vào (`train.csv`).
- `src/`: Chứa mã nguồn chính (`main.py`).
